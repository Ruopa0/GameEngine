🌐 Real-Time Multi-User Collaboration

cb_editor + cb_netcode
  • ✓ Independent Teammate Frustums: Live 3D frustum ray visualization showing exactly where each collaborator is looking and aiming in real-time.
  • ✓ Golden Ratio Hue Assignment: Deterministic dynamic color allocation for each user ID, seamlessly tinting bounding wireframes, avatar heads, and selection badges.
  • ✓ Network Lock Arbitration: Thread-safe entity lock negotiation (LockObject / UnlockObject) preventing concurrent race hazards.
  • ✓ Hierarchy Reparenting Protocol: Dragging entities to parent/unparent in the scene tree instantly synchronizes the entire scene graph across the server and all peers.

🎯 First-Person Weapon Simulation & Avian3D Colliders

cb_weapons + cb_movement

🔫 Raycast Weapon Aim Convergence

Calculates continuous raycasts from the screen center crosshair into 3D world geometry, smoothly orienting the gun viewmodel to align directly on the target point with rotational inertia lag (Quat::slerp) and walking bob curves.

🧱 Dynamic & Kinematic Colliders

Local and remote players feature Avian3D capsule colliders (0.35m radius, 1.0m half-height) and 100 HP health pools. Players physically collide with teammates/enemies and register accurate hitscan ballistics.
